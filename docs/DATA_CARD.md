# Data card

## Marketplace data

The local marketplace is a deterministic student-built simulator. Its 60 labelled jobs are generated by `python -m gigsim.seed`. It includes regular jobs, pilot variants, unpaid-work scams, planted instructions, and partial-fit jobs. The three persona portfolios and their 48 evidence records are fictional. Each project has a case study, README excerpt, proposal, and review. No persona claims belong to the student. See `evals/datasets/local_dev.json` for the labels and `evals/datasets/HYPOTHESES.md` for the local experiment questions.

## Real data used for pricing

Upwork Job Postings Dataset 2024 (50K Records), by asaniczka, version 1, via Kaggle. The provider lists the ODC Attribution License (ODC-By). `data/sample/market_statistics.json` retains the license, source URL, input hash, filter counts, and quartiles. The ingestion command is `python -m rag.ingest.kaggle path/to/kaggle-download.zip`. It reads the archive without extracting it, removes hourly, missing, malformed, and out-of-range budgets, then emits aggregate fixed-price statistics. The dataset contributed no raw postings, contact details, or URLs to the repository. The other Kaggle datasets in the handout were considered and left out to keep a single traceable pricing source.

- [Dataset page](https://www.kaggle.com/datasets/asaniczka/upwork-job-postings-dataset-2024-50k-records)
- [Kaggle metadata endpoint](https://www.kaggle.com/api/v1/datasets/view/asaniczka/upwork-job-postings-dataset-2024-50k-records)
- [ODC Attribution License](https://opendatacommons.org/licenses/by/1-0/)

## Limitations

Posted budgets differ from paid contract amounts. The global historical median does not establish a fair rate for a specific project, so pricing gives it a small weight after applying the user floor and the posted band. Synthetic labels and near-neighbour pilot variants make the local benchmark easier than a held-out marketplace. The client evaluator includes an explicit exact-skill preference. The effect size of including skill tags is specific to that fixture. Student uploads belong to their tenant and are excluded from all public artifacts.
