# Signature extension · X1 Agency mode

In Settings, select **Agency workspace**. Fit Matcher searches the three synthetic portfolios concurrently. It compares how many requirements each candidate can support. A same-category portfolio wins a tie. The writer receives only the selected member's evidence and their tenant's style rule. This is a single-reviewer simulation of team routing.

The evaluation compares the agency router with an AI/ML-only workspace on the same eligible jobs. See `evals/results/agency.csv` and the extension group in `evals/results/summary.json`. The comparison measures eligibility and assignment agreement. A real team would need member consent, availability, tenant membership, and evaluation on ambiguous and cross-functional projects.
